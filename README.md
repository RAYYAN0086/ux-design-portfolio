# UX/UI Design Portfolio

Welcome to my personal UX/UI Design Portfolio website! This repository contains the source code for my frontend web portfolio, designed to showcase my design process, user research, wireframes, prototypes, and final high-fidelity user interface case studies.


---

## 📂 Project Structure

The codebase is kept modular, clean, and extremely lightweight:

```text
portfolio/
├── index.html          # Main homepage layout and portfolio structure
├── style.css           # Custom CSS for modern typography, layout, and responsive grids
├── script.js          # Interactive UI elements (smooth scrolling, mobile menu, animations)
└── ux portfolio/
    └── images/         # Imagery asset folder containing project screenshots and case study assets
        └── image.png
```

---

## ✨ Features

- **Responsive Design:** Optimized for a seamless experience across desktop screens, tablets, and mobile devices.
- **Project Grid:** A structured visual showcase for case studies and visual designs.
- **Clean Typography & Layout:** Designed with a UX-first perspective focusing heavily on readability and visual hierarchy.
- **Interactive UI Elements:** Subtle transitions and interactions to create an engaging browsing experience.

---

## 🛠️ Built With

- **HTML5:** Semantic structure.
- **CSS3:** Flexbox, Grid, and fluid responsive styling.
- **JavaScript (Vanilla):** Dynamic user interactions without bulky frameworks.

---

## 🔧 Getting Started

To view and edit the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd ux-design-portfolio/portfolio
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to open it in any modern browser, or run it via a local development server extension like **Live Server** in VS Code.
